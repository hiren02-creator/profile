# Hiren's Profile Website

A modern, professional portfolio website showcasing expertise in Finance, AI Research, and Inclusive Education.

## ✨ Features

- **Modern Design** - Clean, professional layout with beautiful gradients
- **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations** - Interactive elements with smooth transitions
- **Professional Styling** - Modern color scheme and typography

## 📱 Sections Included

1. **Navigation Bar** - Sticky navigation with smooth scrolling
2. **Hero Section** - Eye-catching introduction with call-to-action buttons
3. **About Section** - Professional background, mission, and location
4. **Skills Section** - 6 key skill areas with icons
5. **Experience Section** - Timeline of professional journey
6. **Contact Section** - Contact information and message form
7. **Footer** - Quick links and social media connections

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript (Vanilla)
- Font Awesome Icons (via CDN)
- Responsive Design
